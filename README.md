# Tower of Hanoi (Python)

This project implements the Tower of Hanoi problem using Python recursion.

## 📌 What it does
- Moves disks between 3 rods
- Follows Tower of Hanoi rules
- Uses recursion to solve the problem step by step

## 🎯 Rules
- Only one disk moves at a time
- A larger disk cannot be placed on a smaller disk
- All disks start on one rod

## 🖥️ Optional Visual Version
This project can be extended using `turtle` graphics to show:
- 3 rods
- Colored disks
- Animated movement (like FreeCodeCamp)
